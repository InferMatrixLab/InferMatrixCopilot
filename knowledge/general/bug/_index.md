# Bug

## 什么时候查这里

- 需要按统一标准给 Bug 定级，或计算 DI / SLO。

## 不放什么

- 某个仓库专属的缺陷跟踪字段、看板流程或自动化脚本。
- 具体 issue 的调查时间线与根因结论（调试方法见 [debug](../debug/_index.md)）。
