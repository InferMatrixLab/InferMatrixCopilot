## Predetermined comparison and limits

Run one matched baseline/candidate pair per stratum as the initial controlled
pilot. Randomize arm order using a recorded seed. Allow at most one bounded
repair per case/arm. There are ten strata and twenty case/arm executions, but an
execution can make multiple native calls. Freeze a `native_call_limits` mapping

internal judgment and repair calls. Legacy plans retain the global 36-native-call ceiling; if
the full workflows cannot fit, report the pilot as unrun or incomplete and revise
the budget explicitly before dispatch. Do not silently expand the sample, count
a multi-call workflow as one native call, or replace failed cases.

Limit each model call to 180 seconds and concurrency to one. Use the same backend
and profile in both arms. For invoiced API execution, require an enforceable
provider spend cap and reserve at most USD 10 across the pilot. An authenticated
subscription-only run may instead use its explicit native-call ceiling; never present
fixed accounting units or unknown subscription usage as measured invoice cost.

case pending reconciliation, without fallback or a new paid call.
The admission ledger conservatively blocks all further dispatch while any call
is unresolved. Each actual provider invocation must reserve independently; case
driver reservations alone do not enforce this protocol.
